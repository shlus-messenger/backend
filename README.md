# Shlus Messenger

Shlus Messenger — это децентрализованный* мессенджер с открытым исходным кодом.

## Технические характеристики

Shlus написан с использованием веб фреймворка Phoenix ( Elixir ), который обеспечивает отказоустойчивость под большой сетевой нагрузкой.

## Установка и запуск

*На текущий момент мессенджер централизованный, поскольку основной функционал находится на стадии разработки. По завершении разработки ядра будет вестить работа по децентрализации сервиса.
